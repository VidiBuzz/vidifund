Configuration Steps

  1. Connect BE5000 to ER7212PC PoE+ port (Port 1-8)
  2. Power is delivered automatically over Ethernet
  3. Download Omada app (iOS/Android) or use web portal
  4. ER7212PC auto-discovers APs (ZTP - Zero Touch Provisioning)
  5. Create SSIDs: "Fortuna_Main" (6GHz + 5GHz) and "Fortuna_Guest" (2.4GHz)
  6. Enable band steering and fast roaming (802.11r)
  7. Set transmit power to 70% for optimal coverage
  8. Schedule reboot weekly (Sunday 3AM)

Installation Best Practices

  • ✓ Mount on ceiling, 8-12 feet high
  • ✓ Position for line-of-sight to main areas
  • ✓ Keep away from metal ducts and mirrors
  • ✓ Maximum 3 APs per controller zone
  • ✓ Enable mesh if running cables is difficult
  • ✓ Use 6GHz for high-speed devices (gaming, 4K/8K)

RJ45 Cable Termination Instructions

You have two RJ45 connectors that need to be spliced onto the cables. This video shows exactly how to terminate the cable ends correctly. Follow these steps carefully to ensure proper wire order and secure connections.

T568B Wire Order (Standard)

Arrange wires in this order from left to right (with clip facing down):

  1. Orange/White
  2. Orange
  3. Green/White
  4. Blue
  5. Blue/White
  6. Green
  7. Brown/White
  8. Brown

Key Steps

  • Strip only 1-1.5 inches of outer jacket
  • Untwist wires and straighten them completely
  • Keep wires flat and in correct T568B order
  • Trim wire ends evenly with sharp cutters
  • Push wires all the way to the front of the connector
  • Crimp firmly - you'll hear a click

Pro Tip: Use a cable tester after crimping to verify all 8 pins are connected properly. If one wire isn't making contact, you'll need to cut and re-do the connector.
